# Velog Posting Guide

## 작성 대상
- 가비서를 통해 실제로 진행한 기술 작업/자동화/인프라 정리

## 스킵 기준
- 실질 작업이 거의 없는 날
- 공개용으로 정리할 가치가 부족한 날

## 공개 전 점검
- 비밀값 제거
- 내부 경로/도메인/개인정보 과다 노출 여부 확인
- 문장 다듬기
- 제목 개선
- 제목 아래 고지 문구 포함 여부 확인

## 고지 문구
제목 바로 아래에 아래 문구를 넣는다.

> _이 글은 하루 동안 진행한 작업을 AI로 정리한 초안을 바탕으로, 사람이 검수·수정해 게시하는 기록입니다._

## 권장 제목 패턴
- `[가비서 작업일지] <주제>`
- `[작업 회고] <주제>`
- `[자동화 기록] <주제>`
