# Velog Drafts

가비서를 통해 진행한 일들을 Velog용 Markdown 초안으로 저장하는 디렉토리입니다.

## 목적
- 전날 진행한 작업을 일기/회고 형태로 기록
- 사람이 검토 후 Velog에 수동 게시
- 게시 전 초안 저장소로 사용

## 파일 규칙
- 경로: `posts/velog/YYYY-MM-DD-gabiseo-log.md`
- 기준 날짜: **작성 시점의 전날**
- 내용이 충분하지 않으면 생성하지 않고 스킵

## 생성 원칙
- 기술 작업, 자동화, 인프라, 운영 흐름, 의사결정, 삽질/해결이 있었을 때만 생성
- 단순 잡담/짧은 확인만 있으면 스킵
- 공개용 초안이므로 민감한 정보/비밀값/개인정보는 제외
- 회고보다 기술 구현 내용과 구조 설명을 우선한다.
- 필요 시 코드/JSON/YAML/프롬프트 일부를 포함할 수 있다.
- 제목 아래에는 글 주제에 맞는 해시태그 한 줄을 넣는다.
- 첫 번째 해시태그는 반드시 `#OpenClaw`로 시작한다.
- 해시태그 아래에는 아래 고지 문구를 포함한다.

예시 해시태그:
`#OpenClaw #가비서 #자동화`

> _이 글은 하루 동안 진행한 작업을 AI로 정리한 초안을 바탕으로, 사람이 검수·수정해 게시하는 기록입니다._
