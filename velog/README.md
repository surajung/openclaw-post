# Velog Drafts

이 디렉토리는 Velog 게시 전 초안을 보관하는 사람용 작업 공간입니다.

## 목적
- 전날 진행한 기술 작업을 게시 후보 문서로 정리
- 날짜 기준으로 초안을 축적
- 사람이 검토 후 Velog에 수동 게시

## 구성
- `TEMPLATE.md` : 초안 기본 템플릿
- `AGENTS.md` : AI 모델이 따라야 하는 단일 하네스 문서
- `YYYY-MM-DD-gabiseo-log.md` : 날짜별 초안 파일

## 운영 방식
- 초안은 자동 생성될 수 있지만, 게시 전에는 반드시 사람이 검토합니다.
- 공개용 문서이므로 민감한 정보, 비밀값, 과도한 내부 정보는 제외해야 합니다.
- 이 디렉토리의 기준은 "바로 게시 가능한 후보 문서"를 만드는 것입니다.

## 문서 역할 분리
- 사람은 이 `README.md`를 봅니다.
- AI 모델은 `AGENTS.md`를 기준으로 작업합니다.
- 결과물 형식은 `TEMPLATE.md`를 따릅니다.

## 참고
초안 구조나 검증 규칙을 바꾸려면 템플릿만 수정하지 말고, `AGENTS.md`, validator, 자동 생성 cron 규칙까지 함께 맞춰야 합니다.
