# Posts Workspace

이 저장소는 가비서를 통해 생성하거나 정리한 게시용 초안을 관리하는 공간입니다.

## 목적
- 게시 전 Markdown 초안 보관
- 날짜 기준 기록 축적
- Git 기반 형상관리 및 백업

## 현재 구성
- `velog/` : Velog 게시용 초안
- `scripts/` : 초안 검증용 로컬 도구

## 운영 원칙
- 공개 전 사람이 직접 검토한다.
- 민감정보, 토큰, 내부 전용 정보는 초안에 포함하지 않는다.
- 날짜 기준으로 초안을 쌓고, 필요하면 주제는 문서 내부에서 정리한다.

## Git 운용
- 이 저장소는 원격 저장소와 연결되어 있으며, 초안 생성 후 자동 commit/push 대상으로 사용할 수 있다.
- 기본 브랜치는 `main`, 기본 remote는 `origin`이다.
